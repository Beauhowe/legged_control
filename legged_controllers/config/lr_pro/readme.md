# 参数解析

```
; standard state weight matrix
Q
{
  scaling 1e+0

  ;; Normalized Centroidal Momentum: [linear, angular] ;;
  (0,0)   15.0     ; vcom_x
  (1,1)   15.0     ; vcom_y
  (2,2)   100.0    ; vcom_z
  (3,3)   10.0     ; L_x / robotMass
  (4,4)   30.0     ; L_y / robotMass
  (5,5)   30.0     ; L_z / robotMass

  ;; Base Pose: [position, orientation] ;;
  (6,6)   1000.0   ; p_base_x
  (7,7)   1000.0   ; p_base_y
  (8,8)   1500.0   ; p_base_z
  (9,9)   100.0    ; theta_base_z
  (10,10) 300.0    ; theta_base_y
  (11,11) 300.0    ; theta_base_x

  ;; Leg Joint Positions: [LF, LH, RF, RH] ;;
  (12,12) 5.0     ; LF_HAA
  (13,13) 5.0     ; LF_HFE
  (14,14) 2.5     ; LF_KFE
  (15,15) 5.0     ; LH_HAA
  (16,16) 5.0     ; LH_HFE
  (17,17) 2.5     ; LH_KFE
  (18,18) 5.0     ; RF_HAA
  (19,19) 5.0     ; RF_HFE
  (20,20) 2.5     ; RF_KFE
  (21,21) 5.0     ; RH_HAA
  (22,22) 5.0     ; RH_HFE
  (23,23) 2.5     ; RH_KFE
}
```
这段是 **MPC 里对「状态误差」的二次代价权重矩阵 $Q$**（配合 $R$ 一起构成跟踪代价）。在 OCS2 四足中，总代价形式大致为

$$
J = \text{scaling} \cdot (x - x_{\text{nom}})^{\top} Q (x - x_{\text{nom}})
$$

**$Q$ 的对角线元素越大，越强迫该状态分量紧贴参考轨迹上的名义值。**

下面分区块解释你文件里的物理意义（顺序与注释一致）：

---

### `scaling 1e+0`

对整个 $Q$ 的全局缩放因子。如果你想整体调整「状态跟踪」的强度，而不需要逐项细改，可以修改它。

---

### 行 183–189：归一化质心动量（6 维）

| 下标           | 物理量                         | 作用                                                      |
|----------------|--------------------------------|----------------------------------------------------------|
| (0,0)–(2,2)    | $v_{\mathrm{com}\,x,y,z}$      | 前向/侧向/垂向 **质心速度** 跟随指令的紧度，越大越“死跟”期望速度 |
| (3,3)–(5,5)    | $L_x/m,\ L_y/m,\ L_z/m$        | **归一化角动量**（角动量除以质量 $m$），越大越抑制质心转动/摆动，步态越“刚性”，控制代价也更高 |

---

### 行 191–197：机体质心位姿（6 维）

| 下标           | 物理量                                | 作用                                                       |
|----------------|---------------------------------------|-----------------------------------------------------------|
| (6,6)–(8,8)    | $p_{\mathrm{base}\,x,y,z}$            | 基座位置相对于参考的权重，越大越不允许机体在平移上偏离名义轨迹 |
| (9,9)–(11,11)  | $\theta_{\mathrm{base}\,z,y,x}$       | 偏航($z$)、俯仰($y$)、滚转($x$)；越大越强调 **保持姿态稳定**（不歪、不晃） |

---

### 行 199–211：关节位置（12 维，LF→LH→RF→RH）

每条腿有三个关节：HAA、HFE、KFE。

- 这些项惩罚 **实际关节角 $q$ 与参考轨迹名义关节角** 的偏差（名义值来自 `reference.info` 的 `defaultJointState`，由参考轨迹生成器推进）。
- **权重大**：腿会贴合名义姿态，动作更规范，但可能限制快速机动或大步幅运动。
- **权重小**：关节动作更自由，MPC 可能利用一些“奇怪姿态”寻求速度/平衡（如常见的外八字与 HAA 相关）。

---

**一句话总结：** 行 178–212 定义了 **MPC 最希望“跟死”参考轨迹的状态维度**——速度、角动量、机体位姿、关节角各自的重要性如何分配。实际调参时，需要在这块和下方的 $R$（控制权重）之间平衡，没有唯一最优解，需结合实机表现细致测试与调整。
